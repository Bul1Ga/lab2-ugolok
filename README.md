# Лабораторная работа 2

Лендинг кофейни «Уголок». За основу взята идея бесплатного шаблона лендинга из Figma Community (категория website templates, в духе FOODZ: шапка, первый экран, о заведении, меню, преимущества, отзывы, контакты).

## Структура

```
index.html
css/
  reset.css
  style.css
js/
  main.js
img/
  hero.jpg
  about.jpg
  coffee-1.jpg
  coffee-2.jpg
  coffee-3.jpg
```

reset.css — с https://webcademy.ru/blog/739/

Шрифты: Manrope и Playfair Display (Google Fonts).

Вёрстка по БЭМ: блоки header, hero, about, menu, card, why, reviews, review, contacts, form, footer.
